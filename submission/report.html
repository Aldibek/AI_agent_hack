F-06Метод GET используется для изменения состояния
Существенный · Некорректность · доказано текстом · R-17, R-18, R-22, R-23
REST type | GETстрока 104
Description | Сохранение порога. Функциональные требования: чтение порогастрока 103
Request URL | Dev: /alerts/saveLimit . Prod: —строка 108

Метод заявлен как GET, а по описанию он сохраняет/заменяет данные. GET по RFC 9110 §9.2.1 — «безопасный» метод только для чтения: его кэшируют прокси, повторяют клиенты и браузеры, параметры (идентификатор карты, сумма) попадают в URL, логи и историю.

Повторный GET от прокси или кэша либо предзагрузка ссылки меняет порог клиента без его действия.
