# Перевод по номеру телефона

Синтетический документ для проверки устойчивости агента (другая структура и нумерация). Не является эталоном качества.

## 1. Назначение
Позволить клиенту быстро и удобно переводить деньги другому клиенту по номеру телефона.

## 2. Бизнес-требования
- **BR-1.** Клиент может перевести до 500 000 тенге в сутки без комиссии.
- **BR-2.** Перевод должен проходить мгновенно.

## 3. Функциональные требования
1. **FR-01.** Пользователь вводит номер телефона в формате +7XXXXXXXXXX и сумму перевода от 100 до 1 000 000 ₸.
2. **FR-02.** Система показывает имя получателя в формате «Имя Ф.» до подтверждения перевода.
3. **FR-03.** При сумме свыше 300 000 ₸ требуется подтверждение по SMS.
4. **FR-04.** Если получатель не найден, система предлагает отправить приглашение и т.д.
5. **FR-05.** Перевод выполняется с любой карты клиента, при необходимости — со счёта.

## 4. Нефункциональные требования
- Сервис должен быть надёжным и выдерживать высокую нагрузку.
- Время ответа API — не более 2 секунд.

## 5. Сценарии приёмки

| Дано | Когда | Тогда |
| :--- | :--- | :--- |
| Баланс 50 000 ₸ | Перевод 20 000 ₸ | Остаток 30 000 ₸ |
| Сумма 350 000 ₸ | Клиент подтверждает перевод | Перевод выполнен без SMS |

## 6. API

| Поле | Значение |
| :--- | :--- |
| **Method** | GET |
| **URL** | `/p2p/transfer` |
| **Description** | Создание перевода |

Ответ 200 — перевод создан. Ответ 409 возвращается при повторном запросе.
